# 视觉与工程规范

## 一、画布与安全区

```
1080 × 1920（9:16）
├─ 顶部 172px   状态栏 + 系列名 HUD
├─ 左右 96px    内容边距
└─ 底部 360px   抖音文案/音乐条覆盖区 —— 任何文字不得进入
```

底部 360px 是硬约束。`qa.mjs` 的 `safe-bottom` 就是量这条线。

**这三个数字只写在模板的 CSS 变量里**（`--pad-x` / `--safe-top` / `--safe-bottom`），
`qa.mjs` 运行时从页面读回来。改安全区只改模板一处，不要在两处各写一遍。

## 二、字体白名单（只有两款）

| 字体 | 权重 | 用途 | 文件 |
|---|---|---|---|
| `LXGW WenKai GB` | 500 | 标题、引文、大数字 | `assets/fonts/kai500.ttf` |
| `Noto Sans SC` | 300 / 500 | 正文、标签、HUD、`<b>` | `assets/fonts/hei300.otf`、`hei500.otf` |

三条硬规则：

1. **不得引入第三种字体**，包括系统默认（`sans-serif` 会 fallback 到微软雅黑）。
2. **`font-weight` 必须与 `@font-face` 声明完全一致**（楷体只有 500）。写 `400` 会静默回退成黑体 —— 这是最隐蔽的 bug。
3. **必须 `document.fonts.load()` 显式等待三个字重**，否则首帧用回退字形渲染，之后不再重绘。

字体已用 GB2312 + 常用符号子集化（19MB → 3.4MB），SIL OFL 1.1，可商用。

## 三、色彩

| 变量 | 值 | 用途 |
|---|---|---|
| `--bg-core` | `#16110C` | 中心暖夜 |
| `--bg-mid` | `#0A090C` | 过渡 |
| `--bg-edge` | `#050507` | 边缘压暗 |
| `--ink` | `#F4EFE6` | 主文字（暖白，不用纯白） |
| `--ink-2` | `#B4AC9C` | 正文 |
| `--ink-dim` | `#6F695C` | 出处、HUD |
| `--gold` | `#E0A94E` | 强调色，`<em>`、数字、图形 |
| `--cyan` | `#5FD0C8` | 次强调，仅用于对比点 |

**金色占比 ≤ 8% 画面**。金色一多，贵气立刻变土气。

## 四、字号阶梯

| 元素 | 字号 | 行高 |
|---|---|---|
| `.num` 大数字 | 300px | 1.0 |
| `.qmark` 引号 | 200px | 0.66 |
| `.title` 标题 | 128px（自动降到 ≥56） | 1.26 |
| `.qtext` 引文 | 76px（自动降到 ≥42） | 1.72 |
| `.body` 正文 | 40px | 1.9 |
| `.label` 说明 | 36px | 1.8 |
| `.unit` 单位 | 38px | — |
| `.kicker` 小标 | 25px，字距 .28em | — |
| `.cite` 出处 | 23px，字距 .16em | — |

标题自动缩字号公式：`px = clamp(888 / (em宽度 × 1.04), 56, base)`。
**低于 56px 就不该再缩了，该删字。**（`build.mjs` 就是这么判的）

## 五、版面骨架

全部**绝对定位**，不用 flex 流式布局：

```
.scene
 ├─ .kicker   绝对定位 top:172  left:96
 ├─ .stack    绝对定位 top:172 bottom:360，内部 flex 纵向居中
 └─ canvas#fx 绝对定位全屏，图形自己算坐标
```

为什么不用流式：`margin-top:auto` 之类的自适应会在内容变长时把元素推出安全区，
而且推出去的方向不可预测。绝对定位 + 显式分区，问题只会在一个方向发生。

带图形的场景，`.stack` 加 `.top`：文字压在上半区，图形占下半区
（图形基线 `H*0.745`，顶部 `H*0.535`），两侧互不侵占。

## 六、动效时间轴（场景内 p ∈ [0,1]）

| 元素 | 出现区间 | 效果 |
|---|---|---|
| 场景整体 | 0–0.055 淡入 / 0.94–1 淡出 | opacity + 轻微 scale |
| `.kicker` | 0.00–0.12 | 上移 16px + 模糊 |
| 标题逐字 | 0.03–0.34 | 每字延迟，上移 30px + blur 16px |
| `.body` | 0.30–0.50 | 上移 24px |
| `.cite` | 0.58–0.76 | 上移 14px |
| 图形 | 0.05–0.72 | 按类型 |

**场景切换不得留空档**：淡入必须 ≤ 5.5% 场景时长，否则出现黑屏（`qa --video` 会报 `black-frame`）。

## 七、图形层（canvas 1080×1920）

| 类型 | 参数 | 视觉 |
|---|---|---|
| `particles` | `n`, `seed` | 缓慢上升的粒子，全屏环境层。**不参与安全区约束** |
| `grid` | `cols`, `rows`, `cell`, `gap`, `highlight` | 方格逐个点亮，第 highlight 个金色脉冲 |
| `curve` | `kind: entropy` | 香农熵曲线，带扫掠进度、切线、当前点读数 |
| `flow` | — | 四点闭环贝塞尔回路，虚线流动 |
| `bars` | `n` | 中间高两侧低的高斯分布柱 |

图形必须满足：**底部不越过 `H - 360`**，顶部不高于正文底部。

## 八、HUD

左上是 `● 系列名 / @账号`，右上是两位编号（自动按场景递增），
底部 2px 渐变进度条。这三样是「系列感」的来源，不要删。

## 九、渲染参数

| 项 | 值 | 说明 |
|---|---|---|
| 分辨率 | 1080×1920 | 抖音竖屏标准 |
| 帧率 | 30fps | 60fps 收益不抵体积 |
| 编码 | libx264 / CRF 18 / yuv420p | 兼容性优先 |
| 音频 | AAC 192k | 无 BGM 时补静音轨，避免部分播放器异常 |
| 单帧耗时 | ~350ms | 45s 片约 8 分钟 |

**20 秒以内可全帧渲染；超过 40 秒先用 `--step 90` 抽帧试片**（体积小、速度快），
确认无误再全量。
